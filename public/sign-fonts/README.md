Print fonts for the review sign (lib/signStudio). Static Regular/Bold
instances of Google Fonts families (Playfair Display, Inter, Poppins, Lora,
Montserrat, DM Serif Display, Nunito, Oswald), taken from the
@expo-google-fonts npm packages (v0.2.3). All are licensed under the SIL
Open Font License 1.1, which allows bundling and embedding in PDFs.
